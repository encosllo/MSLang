# Explanation for `B-C001` (`IncSat`) -- PROPOSED, not yet in the manuscript

- **Block:** `B-C001`, Corollary (`IncSat`), section "Preliminaries".
- **Statement (informal, from the manuscript):** Let `A` be an `S`-sorted set
  and `Φ, Ψ ∈ Eqv(A)`. If `Φ ⊆ Ψ`, then `Ψ-Sat(A) ⊆ Φ-Sat(A)`.
- **Status:** proposed `Explanation` facet (Architecture.md Sections 6, 11a.5).
  It is *not* accepted manuscript prose; the author decides whether to adopt
  it. The manuscript states `B-C001` without proof.
- **Provenance:** reconstructed from the manuscript's own Proposition `B-P002`
  (`PropIncSat`), not from a Lean proof (no Lean counterpart exists yet). Once a

## Proof

Recall that, for `Φ ∈ Eqv(A)` and `X ⊆ A`, `X` is `Φ`-saturated if and only if
`X = [X]^Φ`; and `Φ-Sat(A) = {X ∈ Sub(A) | X = [X]^Φ}` (`B-D014`). Recall also
Proposition `B-P002` (`PropIncSat`): for `Φ, Ψ ∈ Eqv(A)`,

    Φ ⊆ Ψ   if, and only if,   for every X ⊆ A,  [[X]^Ψ]^Φ = [X]^Ψ.

Assume `Φ ⊆ Ψ` and let `X ∈ Ψ-Sat(A)`. Then `X ⊆ A` and `X = [X]^Ψ`. Applying
`B-P002` in the forward direction gives `[[X]^Ψ]^Φ = [X]^Ψ`. Substituting
`X = [X]^Ψ` on the right and in the subscript gives

    [X]^Φ = [[X]^Ψ]^Φ = [X]^Ψ = X.

Hence `X = [X]^Φ`, so `X ∈ Φ-Sat(A)`. Since `X` was an arbitrary element of
`Ψ-Sat(A)`, we conclude `Ψ-Sat(A) ⊆ Φ-Sat(A)`. ∎

## Dependencies used

- `B-D014` (`Eqv`, saturation `[X]^Φ`, `Φ-Sat(A)`).
- `B-P002` (`PropIncSat`), forward implication only.
