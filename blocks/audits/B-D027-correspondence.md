> ## Definitions
>
> - `genSet Sig X : Sub (WSet Sig X)`, at sort `s` and word `P : List (RowAlpha Sig X)`,
>   `genSet Sig X s P` holds iff there exists `x : X s` with
>   `P = [Sum.inr (⟨s, x⟩ : XElem X)]`. So the generators at sort `s` are exactly the
>   length-one words containing the variable letter `inr ⟨s, x⟩` for some `x : X s`.
> - `TAlg Sig X : Alg Sig` is the subalgebra of `WAlg Sig X` generated (in the sense
>   of `Sg`) by `genSet Sig X`, built with `subAlg`:
>   `subAlg Sig (WAlg Sig X).2 (Sg Sig (WAlg Sig X).2 (genSet Sig X))
>     (Sg_isSubalgebra Sig (WAlg Sig X).2 (genSet Sig X))`.
>   Thus its carriers are the *rows that are terms*: word lists built from the
>   generators by repeatedly prefixing an operation letter and concatenating arguments.
> - `TSet Sig X : SSet S := (TAlg Sig X).1` — the carrier family of `TAlg`.
> - `etaX Sig X : SortedMap X (TSet Sig X)` is
>   `fun s x => ⟨[Sum.inr (⟨s, x⟩ : XElem X)],
>     subset_Sg Sig (WAlg Sig X).2 (genSet Sig X) s ⟨x, rfl⟩⟩`.
>   It sends a variable `x : X s` to the generator word `[inr ⟨s,x⟩]` (with the proof
>   that this word lies in the generated subfamily).
> - `Term (Sig) (X) : S → Type u` is an inductive family of syntactic terms:
>   - `var {s} (x : X s) : Term Sig X s`,
>   - `op (p : List S × S) (σ : Sig p)
>       (a : (i : Fin p.1.length) → Term Sig X (p.1.get i)) : Term Sig X p.2`.
> - `termAlg Sig X : Alg Sig := ⟨Term Sig X, fun p σ a => Term.op p σ a⟩` — the
>   bundled term algebra, operations being the `Term.op` constructors.
> - `termEta Sig X : SortedMap X (Term Sig X) := fun _ x => Term.var x` — the
>   inclusion of variables as terms.
>
> Mathematically: `Term` is the free (initial) algebra of terms over the signature
> `Sig` with generators `X`; `termAlg` is its algebra structure with `termEta` the
> variable insertion. It is stated alongside the concrete realization `TAlg`/`TSet`/
> `etaX` as the subalgebra of the word algebra `WAlg` generated by the one-letter
> variable words. (The file does not itself state a theorem identifying the two; it
> only defines both.)
