## Stage 1 -- read-back (fresh agent, Lean only)

> # B-D021 — generated subalgebra and closure operator
>
> Fixed ambient data: a sort set `S : Type u`. A sorted set is `SSet S := S → Type u`
> (a type `A s` for each sort `s`). A signature is `Signature S := List S × S → Type u`,
> giving a type of operation symbols for each pair `p = (w, s)` consisting of a word
> `w : List S` of input sorts and an output sort `s`. For a sorted set `A`:
>
> - `wordProd A w := (i : Fin w.length) → A (w.get i)` — dependent tuples of elements
>   of `A` indexed by exactly the positions of the word `w`.
> - `finOp A w s := wordProd A w → A s`.
> - `AlgStruct Sig A := (p : List S × S) → Sig p → finOp A p.1 p.2` — for every arity
>   `p = (w, s)` and every symbol `σ : Sig p`, an actual operation taking a `w`-indexed
>   tuple of elements of `A` to an element of `A s`.
> - `Sub A := ∀ s, Set (A s)` — a subfamily (a subset `X s ⊆ A s` for each sort).
> - `Subset X Y := ∀ s, X s ⊆ Y s`.
>
> ## Definitions
>
> - `MemSg Sig F X : (s : S) → A s → Prop` is an inductive family expressing "the
>   element `a : A s` lies in the subalgebra generated by `X`". Its constructors are:
>   - `hyp s a : a ∈ X s → MemSg … s a` — every element of `X` is generated.
>   - `op p σ a : (∀ i, MemSg … (p.1.get i) (a i)) → MemSg … p.2 (F p σ a)` — the
>     result of applying an operation `F p σ` to a tuple all of whose components are
>     generated is generated. Here `p : List S × S`, `σ : Sig p`, and
>     `a : wordProd A p.1`. This is precisely the inductive closure of `X` under all
>     the operations; membership is generated by finitely many operation applications.
> - `Sg Sig F X : Sub A := fun s => {a | MemSg Sig F X s a}` — the generated
>   subfamily, as a predicate.
> - `IsGenerating Sig F X : Prop := ∀ s, Sg Sig F X s = Set.univ` — `X` generates
>   `A` iff for every sort `s` the generated set is the whole carrier `A s`.
>
> Note the later-defined supporting predicates used below:
>
> - `IsSubalgebra Sig F X : Prop := ∀ p σ a, (∀ i, a i ∈ X (p.1.get i)) → F p σ a ∈ X p.2`
>   — stability of `X` under all operations.
> - `IsClosureOperator c : Prop`, for `c : Sub A → Sub A`, is the conjunction
>   `(∀ X, Subset X (c X)) ∧ (∀ X Y, Subset X Y → Subset (c X) (c Y)) ∧ (∀ X, c (c X) = c X)`
>   — extensive, monotone, idempotent.
>
> ## Theorems
>
> - `subset_Sg Sig F X : Subset X (Sg Sig F X)`. For every sort `s` and every
>   `a ∈ X s`, `a ∈ Sg Sig F X s`. Immediate from `MemSg.hyp`.
> - `Sg_isSubalgebra Sig F X : IsSubalgebra Sig F (Sg Sig F X)`. For every arity
>   `p = (w, s)`, symbol `σ`, and tuple `a : wordProd A w`, if each component `a i`
>   lies in `Sg` at sort `w.get i`, then `F p σ a` lies in `Sg` at sort `s`. This is
>   exactly `MemSg.op`.
> - `Sg_least Sig F {X Y} (hY : IsSubalgebra Sig F Y) (hXY : Subset X Y) :
>   Subset (Sg Sig F X) Y`. For any subfamily `Y` that is closed under the operations
>   and contains `X`, every generated element of `X` belongs to `Y`: for all `s`, if
>   `a ∈ Sg Sig F X s` then `a ∈ Y s`. Proved by induction on the generation
>   derivation (`hyp` uses `hXY`; `op` uses closure of `Y` pointwise via the induction
>   hypothesis). Quantifier structure: `Y` and the hypotheses are fixed first, the
>   conclusion is a sortwise inclusion.
> - `Sg_monotone Sig F {X Y} (h : Subset X Y) : Subset (Sg Sig F X) (Sg Sig F Y)`.
>   If `X ⊆ Y` sortwise then the generated sets satisfy `Sg X ⊆ Sg Y` sortwise.
>   Derived from `Sg_least` applied with `Y := Sg Sig F Y`, using that `Sg Sig F Y`
>   is a subalgebra and contains `Y ⊇ X`.
> - `Sg_idem Sig F X : Sg Sig F (Sg Sig F X) = Sg Sig F X`. Generating from the
>   generated set gives the same subfamily (equality of subfamilies, proved by
>   antisymmetry of sortwise inclusion: one direction from `Sg_least` with
>   `Y := Sg Sig F X`; the other from `Sg_monotone` applied to `subset_Sg`).
> - `Sg_isClosureOperator Sig F : IsClosureOperator (Sg Sig F)`. The map
>   `X ↦ Sg Sig F X` is extensive (`subset_Sg`), monotone (`Sg_monotone`), and
>   idempotent (`Sg_idem`), hence a closure operator on subfamilies.
>
> Mathematically: `Sg` is the subalgebra generated by `X`, it is the least
> subalgebra containing `X`, and generation is a closure operator.
