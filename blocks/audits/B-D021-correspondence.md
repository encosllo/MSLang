## Stage 1 -- read-back (fresh agent, Lean only)

> # B-D021 — informal read-back
>
> ## Ambient setup
>
> Fix a universe `u` and a sort type `S : Type u`.
>
> - `SSet S := S → Type u`; a fixed `A : SSet S` is a many-sorted carrier family.
> - `Sub A := ∀ s, Set (A s)` (many-sorted subsets);
>   `Subset X Y := ∀ s, X s ⊆ Y s` (sortwise inclusion).
> - `Signature S := List S × S → Type u`. A signature assigns to each *profile*
>   `p : List S × S` (a finite list of input sorts `p.1` and one output sort
>   `p.2`) a type `Sig p` of operation symbols of that profile.
> - `wordProd A w := (i : Fin w.length) → A (w.get i)`. For a list of sorts `w`,
>   this is the product of the carriers indexed by `w`: an argument tuple whose
>   `i`-th entry lies in the carrier of the `i`-th sort of `w`. (For `w = []` this
>   is the one-point type, so nullary operations appear as constants.)
> - `finOp A w s := wordProd A w → A s`. A concrete operation at input list `w`
>   and output sort `s`.
> - `AlgStruct Sig A := (p : List S × S) → Sig p → finOp A p.1 p.2`. An algebra
>   structure: for each profile `p` and each symbol `σ : Sig p`, an actual
>   operation taking a tuple in the product over `p.1` to an element of `A p.2`.
>   (Below, the operation is written `F p σ a` for a tuple `a`.)
> - `IsSubalgebra Sig F X`, for `F : AlgStruct Sig A` and `X : Sub A`: for every
>   profile `p`, symbol `σ : Sig p`, and tuple `a : wordProd A p.1`, if
>   `∀ i, a i ∈ X (p.1.get i)` (all arguments lie in `X` at their sorts), then
>   `F p σ a ∈ X p.2`. Reading: `X` is closed, sort by sort, under all operations
>   of the algebra.
>
> ## Inductive generation
>
> - `MemSg Sig F X : (s : S) → A s → Prop` is the inductively generated predicate
>   "is in the subalgebra generated by `X`", with the two constructors:
>   - `hyp s a : a ∈ X s → MemSg Sig F X s a` — every generator is generated;
>   - `op p σ a : (∀ i, MemSg Sig F X (p.1.get i) (a i)) →
>       MemSg Sig F X p.2 (F p σ a)` — the result of an operation applied to
>     already-generated arguments is generated.
>
>   It is the least family satisfying these rules; recursion/induction on a
>   `MemSg` derivation is used throughout the file.
>
> - `Sg Sig F X := fun s => {a | MemSg Sig F X s a}`, the many-sorted subalgebra
>   generated by `X`.
>
> - `IsGenerating Sig F X := ∀ s, Sg Sig F X s = Set.univ`. Reading: `X`
>   generates the whole algebra at every sort (the generated subalgebra is the
>   full carrier family).
>
> ## Theorems
>
> 1. `subset_Sg Sig F X : Subset X (Sg Sig F X)`.
>    Every element of `X` lies in the generated subalgebra, directly by `hyp`.
>
> 2. `Sg_isSubalgebra Sig F X : IsSubalgebra Sig F (Sg Sig F X)`.
>    The generated subobject is closed under all operations. For a tuple `a` with
>    all `a i ∈ Sg … (p.1.get i)`, one applies `MemSg.op` to the derivations
>    `ha`.
>
> 3. `Sg_least Sig F {X Y} (hY : IsSubalgebra Sig F Y) (hXY : Subset X Y) :
>      Subset (Sg Sig F X) Y`.
>    If `Y` is a subalgebra containing `X`, then it contains the whole generated
>    subalgebra: `Sg X` is the least subalgebra containing `X`. Proved by induction
>    on the derivation of `MemSg Sig F X`; the `hyp` case gives `a ∈ Y` from `hXY`,
>    the `op` case applies the closure hypothesis `hY`.
>
> 4. `Sg_monotone Sig F {X Y} (h : Subset X Y) :
>      Subset (Sg Sig F X) (Sg Sig F Y)`.
>    Generation is monotone in the generating set: if `X ⊆ Y` then `Sg X ⊆ Sg Y`.
>    Obtained from (3) applied to `Y' := Sg Y`, using (2) and (1).
>
> 5. `Sg_idem Sig F X : Sg Sig F (Sg Sig F X) = Sg Sig F X`.
>    Generation is idempotent, by antisymmetry of `Subset` at each sort:
>    `Sg (Sg X) ⊆ Sg X` from (3) with `Y := Sg X` (which is a subalgebra by (2)),
>    and `Sg X ⊆ Sg (Sg X)` from (4) applied to (1).
>
> 6. `Sg_isClosureOperator Sig F : IsClosureOperator (Sg Sig F)`.
>    The triple: extensivity `subset_Sg` (1), monotonicity `Sg_monotone` (4), and
>    idempotence `Sg_idem` (5). So `Sg Sig F` is a closure operator on `Sub A`.
>
> 7. `MemSg_mono Sig F {X Y} (h : Subset X Y) :
>      ∀ (s : S) (a : A s), MemSg Sig F X s a → MemSg Sig F Y s a`.
>    Pointwise monotonicity of the generated predicate: if `X ⊆ Y`, every `X`-
>    derivation is an `Y`-derivation. Structural recursion: `hyp` case maps the
>    membership via `h`; `op` case recurses on each argument derivation.
>
> 8. `Sg_isAlgebraic Sig F : IsAlgebraic (Sg Sig F)`.
>    Every element of `Sg X` is generated from a pointwise-finite subfamily of
>    `X`. Proved by induction on the `MemSg Sig F X` derivation:
>    - `hyp s a (hx : a ∈ X s)`: take `F = Function.update (fun u => ∅) s {a}`,
>      which equals `{a}` at sort `s` and `∅` elsewhere; then `F ⊆ X` (using `hx`),
>      each `F t` is finite, and `a ∈ Sg F s` by `MemSg.hyp`.
>    - `op p σ a` with inductive hypothesis `ih i : ∃ F, F ⊆ X ∧ (∀ t, F t finite)
>      ∧ MemSg Sig F (F) (p.1.get i) (a i)` for each `i`: choose such `X' i` for
>      every `i` (`choose`). Take `F t := ⋃ i, X' i t`. Then `F ⊆ X` (union of
>      subfamilies of `X`), each `F t` is finite (a finite union — over the
>      finite index `Fin p.1.length` — of finite sets), and `F p σ a ∈ Sg F p.2`
>      by `MemSg.op`, using `MemSg_mono` (7) to lift each `hX'gen i` into the union
>      `F`.
>
