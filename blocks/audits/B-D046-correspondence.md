> ## New definitions specific to this file
>
> - `complA X : Sub A` for `X : Sub A` is the sortwise complement:
>   `complA X = fun s => (X s)ᶜ`.
> - `deltaSub (s : S) (Y : Set (A s)) : Sub A`, defined classically as
>   `Function.update (fun u => (∅ : Set (A u))) s Y`. It is the sorted subset that is

> - `inverseImage f Y : Sub A` for `f : SortedMap A B` and `Y : Sub B` is the
>   sortwise preimage: `inverseImage f Y = fun s => f s ⁻¹' Y s`.

>   `noncomputable` as `deltaSub t (Set.preimage T (L s))`: the sorted subset whose
>   value at sort `t` is `T ⁻¹' (L s)` and which is empty at every other sort.

> ## `IsBPSLanguageFormation` and `bpsLanguageFormations`
>
> `L : (A : SSet S) → Set (Sub (Term Sig A))` assigns to each carrier `A` a family of
> languages over the term algebra on `A`. `IsBPSLanguageFormation Sig L` is the
> conjunction of five axioms:
>
> 1. (Regularity) `∀ A, L A ⊆ regularLanguages Sig (termAlg Sig A)`: every member of
>    `L A` is regular over `termAlg Sig A` (finite syntactic index).
> 2. (Trivial languages) `∀ A, ∀ X : Sub (Term Sig A), IsSat (nabla (Term Sig A)) X
>    → X ∈ L A`: every subset that is sortwise empty-or-total is in `L A`.
> 3. (Preimage under translations) `∀ A, ∀ X : Sub (Term Sig A), X ∈ L A →
>    ∀ (t s : S) (T : (Term Sig A) t → (Term Sig A) s), TlGen Sig (termAlg Sig A) t s T
>    → transPreimage T X ∈ L A`: for every translation `T` and `X ∈ L A`, the sorted
>    subset that is `T ⁻¹' (X s)` at the source sort `t` (and empty elsewhere) is again
>    in `L A`.
> 4. (Boolean closure) `∀ A, ∀ X Y : Sub (Term Sig A), X ∈ L A → Y ∈ L A →
>    (fun s => X s ∪ Y s) ∈ L A ∧ (fun s => X s ∩ Y s) ∈ L A ∧ complA X ∈ L A`:
>    `L A` is closed under sortwise union, sortwise intersection, and sortwise
>    complement.
> 5. (Preimage along surjective homomorphisms) `∀ A B (M : Sub (Term Sig B)), M ∈ L B →
>    ∀ f : SortedMap (Term Sig A) (Term Sig B), IsAlgHom Sig (termAlg Sig A).2
>    (termAlg Sig B).2 f → (∀ s, Function.Surjective (fun x => prAlg Sig (termAlg Sig B).2
>    (congCogenerated Sig (termAlg Sig B) M) (congCogenerated_isCongruence Sig (termAlg Sig B) M)
>    s (f s x))) → inverseImage f M ∈ L A`.
>    In words: if `M ∈ L B` and `f : Term Sig A → Term Sig B` is a term-algebra
>    homomorphism whose composite with the projection to `Term Sig B / congCogenerated M`
>    is surjective at every sort, then the sortwise inverse image `f ⁻¹' M` is in `L A`.
>    Note that, unlike the corresponding fourth axiom in B-D045, no saturation
>    hypothesis is imposed here: the conclusion is directly `inverseImage f M ∈ L A`.
>
> `bpsLanguageFormations Sig := {L | IsBPSLanguageFormation Sig L}`.
>
