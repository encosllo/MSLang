> # B-D012 — informal read-back
>
> ## Ambient setup
>
> Fix `S : Type u`, `SSet S := S → Type u`, a fixed `A : SSet S`, and
> `Sub A := ∀ s, Set (A s)` (many-sorted subsets). `Subset X Y := ∀ s, X s ⊆ Y s`
> (sortwise inclusion).
>
> - `Sub_iInter D`, for `D : Set (Sub A)`, is
>   `fun s a => ∀ X : Sub A, X ∈ D → a ∈ X s` — the sortwise intersection of the
>   members of `D`.
>
> - `Sub_iUnion D`, for `D : Set (Sub A)`, is
>   `fun s a => ∃ X : Sub A, X ∈ D ∧ a ∈ X s` — the sortwise union of the members
>   of `D`: at sort `s`, `a` lies in the union iff it lies in `X s` for at least
>   one `X ∈ D`.
>
> - `IsClosureSystem C`, for `C : Set (Sub A)`, is the conjunction of:
>   - `(fun s => (Set.univ : Set (A s))) ∈ C` (the full subobject is in `C`);
>   - for every `D : Set (Sub A)` with `D ⊆ C` and `D.Nonempty`, the intersection
>     `Sub_iInter D ∈ C`.
>
> - `IsAlgebraicClosureSystem C`, for `C : Set (Sub A)`, is the conjunction of:
>   - `IsClosureSystem C`;
>   - for every `D : Set (Sub A)` such that `D ⊆ C`, `D.Nonempty`, and `D` is
>     *directed* under `Subset` — i.e.
>     `∀ X ∈ D, ∀ Y ∈ D, ∃ Z ∈ D, Subset X Z ∧ Subset Y Z` (any two members have a
>     common upper bound in `D`) — the union `Sub_iUnion D` again belongs to `C`.
>
>   Reading: a closure system (closed under nonempty intersections, containing the
>   top) that is additionally closed under directed unions of its members.
>
> - `IsAlgebraic c`, for `c : Sub A → Sub A`: for every `X : Sub A`, sort `s`, and
>   `a : A s` with `a ∈ c X s`, there exists `F : Sub A` with `Subset F X`
>   (`F ⊆ X`), `(∀ t, (F t).Finite)` (every fiber of `F` is finite), and
>   `a ∈ c F s`. Reading: each element of `c X` is already generated by a finite
>   subfamily of `X`.
>
