> ## Setting (what the vocabulary means)
>
> `S` is a fixed type of **sorts**; a many-sorted signature `Sig` assigns to each
> profile `p = (List S × S)` a type `Sig p` of operation symbols.
>
> * `SSet S = (s : S) → Type u`; `Alg Sig` is a pair `⟨A, F⟩` with `A : SSet S` and
>   `AlgStruct Sig A` interpreting each operation as `wordProd A p.1 → A p.2`
>   (`wordProd A w = (i : Fin w.length) → A (w.get i)`, `finOp A w s = wordProd A w → A s`).
> * `SortedEqv A` — sorted family of equivalence relations; `SortedMap A B` — sorted
>   family of functions; `Sub A = (s : S) → Set (A s)` (a sorted subfamily).
> * `Term Sig X : S → Type u` — sorted terms, generated by `var` and `op`;
>   `termAlg Sig A` — the term algebra.
> * `sortedEqvLe Φ Ψ` — Φ refines Ψ; `sortedEqvInf Φ Ψ` — pointwise intersection
>   (infimum); `sortedEqvLe_antisymm` — mutual refinement implies equality.
> * `IsSat Φ X` — `X` is saturated by `Φ` (a union of `Φ`-classes).
> * `IsCongruenceFormation Sig G` — a family assigning to each sorted set `A` a set
>   `G A` of congruences of `termAlg Sig A`.
> * `langFormationOf Sig G A` — the family (set) of **languages** at `A`, i.e.
>   subfamilies of `Term Sig A` saturated by some congruence in `G A`.
> * `mem_langFormationOf_iff` — the defining characterization:
>   `L ∈ langFormationOf Sig G A ↔ ∃ Φ ∈ G A, IsSat Φ L`.
> * `sat Φ X` — saturation of `X` by `Φ`; `complA X` — the pointwise complement
>   `(s ↦ (X s)ᶜ)`; `nabla A` — the universal (top) sorted equivalence on `A`;
>   `nabla_isCongruence` — it is a congruence of every algebra.
> * `ker f` — the kernel sorted equivalence of `f`.
> * `closesUnderEtl_of_closesUnderTl`, `closesUnderTl_of_closesUnderEtl` — the two
>   translation-closure conditions are equivalent.
> * `closesUnderEtl_of_isCongruence` — congruences are elementary-translation closed.
> * `congruence_of_closesUnderEtl` — an elementary-translation-closed equivalence is a
>   congruence; `isCongruence_iff_closesUnderEtl` — the iff.
> * `congCogenerated Sig A L` — the largest congruence of `A` saturating `L`;
>   `congCogenerated_isCongruence`; `congCogenerated_le_charEqv` (it refines the

>   `IsSat Φ L ↔ Φ ≤ congCogenerated Sig A L`.
> * `sat_antitone` — if `Φ ≤ Ψ` and `X` is `Ψ`-saturated then `X` is `Φ`-saturated.
> * `sat_compl` — the complement of a saturated subfamily is saturated by the same
>   equivalence.
> * `IsElemTranslation`, `TlGen` — elementary translations and the generated
>   translations (identity, elementary, composition).

> ## Main proved theorems
>
> 1. **`langFormationOf_union`.** If `G` is a congruence formation and `L`, `L'` both
>    lie in `langFormationOf Sig G A`, then the pointwise **union**
>    `(s ↦ L s ∪ L' s)` lies in `langFormationOf Sig G A`.
>    Proof idea: witnesses `Φ, Ψ ∈ G A` saturating `L, L'` combine to the infimum
>    `Φ ∧ Ψ` (which is in `G A`), and `isSat_union` gives saturation of the union using
>    that `Φ ∧ Ψ ≤ Φ` and `Φ ∧ Ψ ≤ Ψ` with `sat_antitone`.
>
> 2. **`langFormationOf_inter`.** Same hypotheses, but conclusion: the pointwise
>    **intersection** `(s ↦ L s ∩ L' s)` lies in `langFormationOf Sig G A`.
>
> 3. **`langFormationOf_compl`.** If `L ∈ langFormationOf Sig G A`, then its pointwise
>    **complement** `complA L` lies in `langFormationOf Sig G A`. (Same witness `Φ`,
>    using `sat_compl`.)
>
> 4. **`langFormationOf_empty`.** The constantly-empty subfamily
>    `(s ↦ ∅ : Set (Term Sig A s))` lies in `langFormationOf Sig G A`. (Immediate from
>    `langFormationOf_nabla` and `nabla_sat_empty`.)
>
> 5. **`langFormationOf_univ`.** The constantly-universal subfamily
>    `(s ↦ Set.univ)` lies in `langFormationOf Sig G A`. (From `langFormationOf_nabla`
>    and `nabla_sat_univ`.)
>
> Taken together these say that each `langFormationOf Sig G A` is a Boolean subalgebra
> of the pointwise powerset algebra `∏_s 𝓟(Term Sig A s)`.
>
