## Stage 1 -- read-back (fresh agent, Lean only)

> # B-D013 — informal read-back
>
> ## Ambient setup
>
> Fix `S : Type u`, `SSet S := S → Type u`, a fixed `A : SSet S`, and
> `Sub A := ∀ s, Set (A s)` (many-sorted subsets). `Subset X Y := ∀ s, X s ⊆ Y s`
> (sortwise inclusion).
>
> `suppSub` is **not** declared in this file (it is external); from its use it is
> the *support* map, sending a many-sorted subset `X` to the set of sorts `s` for
> which `X s` is nonempty. The definitions below are read using that meaning.
>
> - `IsUniform c`, for `c : Sub A → Sub A`: for all `X Y : Sub A`, if
>   `suppSub X = suppSub Y` (same support), then `suppSub (c X) = suppSub (c Y)`.
>   Reading: `c` cannot distinguish subobjects with the same support — the support
>   of the closure depends only on the support of the input.
>
> - `IsClosureOperator c`, for `c : Sub A → Sub A`, is the conjunction of:
>   extensivity `∀ X, Subset X (c X)`; monotonicity
>   `∀ X Y, Subset X Y → Subset (c X) (c Y)`; idempotence `∀ X, c (c X) = c X`.
>
> - `IsAlgebraic c`, for `c : Sub A → Sub A`: for every `X : Sub A`, sort `s`, and
>   `a : A s` with `a ∈ c X s`, there exists `F : Sub A` with `Subset F X` and
>   `(∀ t, (F t).Finite)` and `a ∈ c F s`. Reading: every element of `c X` is
>   generated by a pointwise-finite subfamily of `X`.
>
> - `IsUniformAlgebraicClosureOperator c`, for `c : Sub A → Sub A`, is the
>   conjunction `IsClosureOperator c ∧ IsAlgebraic c ∧ IsUniform c`. Reading: a
>   closure operator that is simultaneously algebraic and uniform (in the support
>   sense above).
>
> ## Theorems
>
> There are **no theorems** in this file. It contains only definitions
> (`IsUniform`, `IsUniformAlgebraicClosureOperator`, `IsAlgebraic`,
> `IsClosureOperator`, `SSet`, `Sub`, `Subset`); no assertion is made and nothing
> is proven.
