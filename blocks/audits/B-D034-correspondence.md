> ## `formationGenerating Sig (M : Set (Alg Sig)) : Set (Alg Sig)`
>
> `formationGenerating Sig M := ⋂₀ {F | IsAlgebraFormation Sig F ∧ M ⊆ F}`.
>
> This is the intersection of all classes `F` of `Sig`-algebras that are algebra
> formations and contain `M`. Equivalently, the least algebra formation containing
> `M` (the formation generated by `M`), presented as a generalized intersection over
> the set of admissible `F`. Note `F` is a bound variable ranging over
> `Set (Alg Sig)`, and the defining set comprehension collects exactly those `F`.
>
> ## Supporting definitions
>
> - `AlgStruct Sig A := (p : List S × S) → Sig p → finOp A p.1 p.2`.
> - `HOperator Sig F : Set (Alg Sig) :=
>    {A | ∃ B ∈ F, ∃ f : SortedMap B.1 A.1, IsEpiAlg Sig B.2 A.2 f}`
>   (homomorphic images of members of `F`).
> - `IsAlgHom Sig FA FB f : Prop :=
>    ∀ (p) (σ : Sig p) (a : wordProd A p.1),
>      f p.2 (FA p σ a) = FB p σ (fun i => f (p.1.get i) (a i))`.
> - `IsAlgebraFormation Sig F : Prop := HOperator Sig F ⊆ F ∧ PFsdOperator Sig F ⊆ F`
>   (closure under homomorphic images and under finite subdirect products).
> - `IsEpiAlg Sig FA FB f := IsAlgHom Sig FA FB f ∧ ∀ s, Function.Surjective (f s)`.
> - `IsMonoAlg Sig FA FB f := IsAlgHom Sig FA FB f ∧ ∀ s, Function.Injective (f s)`.
> - `IsSubdirectEmbedding Sig FA Ai f :=
>    IsMonoAlg Sig FA (iAlg Sig Ai).2 f ∧
>      ∀ i : ι, ∀ s : S, Function.Surjective (fun a : A s => f s a i)`
>   (injective homomorphism into a product whose image projects onto every factor).
> - `PFsdOperator Sig F : Set (Alg Sig) :=
>    {A | ∃ (ι : Type u) (_ : Fintype ι) (C : ι → Alg Sig), (∀ i, C i ∈ F) ∧
>          ∃ f : SortedMap A.1 (iAlg Sig C).1, IsSubdirectEmbedding Sig A.2 C f}`
>   (finite subdirect products of members of `F`).
> - `SSet S := S → Type u`; `Signature S := List S × S → Type u`;
>   `SortedMap A B := ∀ s, A s → B s`;
>   `finOp A w s := wordProd A w → A s`;
>   `wordProd A w := (i : Fin w.length) → A (w.get i)`.
> - `iAlg Sig A : Alg Sig :=
>    ⟨fun s => ∀ i, (A i).1 s,
>     fun p σ b => fun i => (A i).2 p σ (fun j => b j i)⟩` (coordinatewise product).
>
